Paneldeck 2.0 adds a second main area next to the Terminal Hub: a **todo list** that grows into a small **ticket system** when you switch on *expert mode*. The Terminal Hub itself is unchanged. This is a major version because of the new main structure (window title bar with tabs); existing settings, sessions, prompts and themes keep working, and the agent interface (MCP) only gains new tools.

> Independent open-source project – not affiliated with, endorsed by or reviewed by Anthropic.
> The installer and `paneldeck.exe` are **not code-signed** yet, so Windows SmartScreen may warn on first start ("More info" → "Run anyway"). See the README for details.

### Highlights

- **A title bar with tabs:** *Terminal Hub* (as before) and *Todo list*. Switch with a click, `Ctrl+1` / `Ctrl+2` or `Alt+Shift+1` / `Alt+Shift+2`. Paneldeck now draws its own window frame; on Windows 11 with rounded corners and the Snap Layouts menu at the maximize button.
- **Simple mode** (default): a quick to-do list – cards with an optional title and text, tags that are created while you type, check boxes, drag & drop ordering, filters, undo/redo (`Ctrl+Z` / `Ctrl+Y`), and permanent deletion only after a 3-second safety timer.
- **Expert mode** (one switch): projects with a key (`PAN-12`) and an accent color, **ticket types you design yourself** (defaults: Epic, User story, Dev task, Subtask, Defect) with your own fields (text, rich text/Markdown, check box, dropdown, number, ticket link, terminal, version, milestone, dates, labels), **statuses and workflows per type** with required fields, conditions and automatic values per transition, link types (ticket, terminal, URL, git branch), kinds of work for time tracking, and templates to reuse a project's setup.
- **Kanban boards:** several boards per project with their own columns and filters; dragging a card is a status change with all workflow rules.
- **Terminals and tickets belong together:** link a ticket to a terminal session from a small search in the terminal header; the ticket key shows as a chip in the header and the sidebar (a click opens the ticket), and the command palette finds tickets. Links to closed sessions stay as "ended".
- **Agent interface:** 18 new MCP tools (33 in total) – `list_todos`, `add_todo`, `set_todo_done` and, in expert mode, `list_projects`, `get_project`, `search_tickets` (also with a `query` in the query language), `get_ticket`, `get_time_entries`, `list_sprints`, `get_sprint`, `list_versions`, `create_ticket`, `update_ticket`, `transition_ticket`, `add_comment`, `log_time`, `link_ticket`, `link_terminal`. An agent only gets the tools of the current mode, follows the same rules as the window (required fields, hierarchy, workflows), can never delete tickets or change types, workflows or projects, and every change shows up as a short toast and in the ticket history with the agent's session name.
- **A local database with automatic backups:** everything of the new areas lives in `paneldeck.db` in the data folder. *Settings → Data & backup* makes a copy every 24 hours by default (two are kept), catches up missed backups at the next start, offers "Back up now", a free choice of the backup folder and **Restore** from a list. Paneldeck also backs up before every database update.
- **Tickets in full:** a ticket list with a query bar, create dialog, detail page or side panel, Markdown fields with a **Text | Visual** switch and clickable ticket keys, comments, change history (window, quick menu, agent or import), undo/redo (also on the board), clone, change type or move to another project, flag and star, time tracking, and a *Back* path to wherever you came from.
- **A query language** (JQL-like) with autocomplete and error messages in English and German, saved filters, your own keywords (`IS favorite`, `SORT BY favorites`) a **Search** tab with a results table and a **complete help page** with examples – for example `type = Epic AND "Release version" = 2.0.0 AND status IN (Done, "Development finished") ORDER BY priority`.
- **Optional sprints, versions and milestones:** a *Backlog* tab with drag & drop planning, one active sprint per project, burndown chart with ideal line and work days, sprint report and velocity, and a *Releases* tab for versions and milestones with progress.
- **Quick actions and the quick menu** (`.` in a ticket): preset "create ticket", "change status" and "start a session" buttons per type (edited in the *Quick actions* tab), and a fast way to fill in fields or change the status from the keyboard – it asks for required fields when a status change needs them.
- **Dashboards** with freely arranged tiles (searches, sprint, burndown, charts, booked time, favorites, all projects), per project or global, exportable as JSON.
- **Export and import** (*Templates & backup* tab): project backup (JSON), tickets (CSV) and type/field templates; the import always creates a new project and never changes existing data.

### Added

- Window title bar with the tabs *Terminal Hub* and *Todo list* (shortcuts `Ctrl+1` / `Ctrl+2`, `Alt+Shift+1` / `Alt+Shift+2`, editable under *Settings → Shortcuts*), Windows 11 rounded corners and Snap Layouts flyout.
- Local SQLite database `paneldeck.db`; automatic backups (interval, number of copies, backup folder), "Back up now", restore from a list, a backup before every migration.
- Simple to-do list with tags, filters, drag & drop ordering, completed cards hidden or deleted (with a 3-second safety timer) and undo/redo with a configurable history (3, 5, 10, 25, 50 or 100 steps).
- Expert mode: projects, ticket types with hierarchy rules, twelve field types, per-type workflows with transition rules, link types (including the built-in, undeletable *Terminal* type), kinds of work, templates, kanban boards (source: all tickets or a saved filter; optionally only the active sprint), tickets with comments, links, history, time tracking, clone and change type/move.
- Ticket screens: list, create dialog, detail page or side panel, Markdown fields, quick menu and quick action editor, undo/redo with `Ctrl+Z` / `Ctrl+Y`.
- Query language with autocomplete, saved filters, a keyword editor, a *Search* tab and a help page; backlog, sprints, burndown, velocity, versions and milestones; dashboards; project backup (JSON) and ticket CSV export/import.
- Ticket–terminal links with a search in the terminal header, key chips in the header and the sidebar (a click opens the ticket), ticket results in the command palette and a picker for fields of type *Terminal*.
- Toasts: short messages at the bottom right (up to five, ten seconds each).
- MCP: 18 new tools (see above), the error codes `wrong_mode`, `invalid_query` and `feature_disabled`, and an overview line in *Settings → Agents* that shows which tool group applies.

### Changed

- The main window is now frameless with Paneldeck's own title bar; the Terminal Hub below it looks and works as before.
- New data: `paneldeck.db` (with `paneldeck.db-wal` / `-shm` while running) and a `backups/` folder in the data folder; `settings.json` gains `backup_interval_hours`, `backup_keep`, `backup_dir` and `undo_steps`. Existing files keep their format.

### Upgrade notes

- **Update from 1.0.x:** install over the old version or replace the portable folder; sessions, projects, prompts, themes and settings are kept. The first start creates `paneldeck.db`; nothing else changes until you open the *Todo list* tab.
- **Going back to 1.x:** Paneldeck 1.x ignores `paneldeck.db` (your to-dos and tickets stay in the file, untouched). Back up the data folder before going back.
- **Newer database:** if the data folder was written by a newer Paneldeck, this version does not touch the database and shows a message instead.
- **Agents:** the tool list now depends on the *Expert mode* switch of the *Todo list* tab. Reload the tool list (`/mcp` in Claude Code) after switching. Existing tools and fields are unchanged.
- The query language, sprints, dashboards and the ticket screens are described in the README. The database is at schema version 7.
