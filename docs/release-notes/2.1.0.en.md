Paneldeck 2.1 is about running Paneldeck your way: **command-line options and profiles** that run side by side, **several windows**, a **configurable system prompt** for agents, a Terminal Hub that **starts empty**, and a **self-update** from GitHub Releases. It is a minor version: settings, sessions, the database and the agent interface (MCP) stay compatible – one behaviour change at the command line is listed under *Upgrade notes*.

> Independent open-source project – not affiliated with, endorsed by or reviewed by Anthropic.
> The installer and `paneldeck.exe` are **not code-signed** yet, so Windows SmartScreen may warn on first start ("More info" → "Run anyway"). See the README for details.

### Highlights

- **Command line and profiles:** `--data-dir <folder>`, `--profile <name>`, `--backup-dir <folder>`, `--lang en|de`, `--no-tray`, `--reset-settings`, `--no-update-check`, `--version` and a detailed `--help` with an example for every option. The data folder is looked up in a fixed order (`--data-dir`, `PANELDECK_DATA`, portable folder next to the exe, `%APPDATA%\Paneldeck`), and *Settings → About* shows which one is active and why. Profiles (`<data folder>\profiles\<name>`) run as separate instances side by side.
- **Integrations per instance:** a profile instance gets its own autostart entry (`Paneldeck (work)`) and its own MCP server name (`paneldeck-work`), with the right parameters. The Explorer context menu exists once and starts the instance that switched it on last.
- **Several windows:** Ctrl+click on the *Terminal Hub* or *Todo list* tab opens it in a new window. Each Terminal Hub window has its own sessions; to-do windows share the same data. Windows and their sessions are restored after a restart.
- **An empty start:** Paneldeck no longer opens a default terminal; the empty Terminal Hub shows the ways to start one. Sessions from the previous run are restored as before.
- **System prompt for agents:** agents that connect over MCP receive a detailed guide (levels, `whoami` first, safety rules, the tools they can use right now, error codes) in the `initialize` reply. Edit it under *Settings → Agents → System prompt* – English or German, placeholders `{{tools}}`, `{{level}}`, `{{mode}}`, `{{version}}`, preview, copy and save as `.md`; your template is stored as `system-prompt.md` in the data folder.
- **Self-update:** *Settings → About → Check for updates*, or an automatic check at most once a day (**off by default**). An update button appears in the title bar; installed copies run the new setup silently, portable copies replace `paneldeck.exe`. Every download is checked against the new release asset `SHA256SUMS.txt`, your sessions are restored after the restart, and a major version jump shows a warning and backs up the database first. Agents cannot trigger updates.
- **New documentation:** the README is now a short landing page; the guides live in `docs/en/` and `docs/de/` (terminals, windows, Claude Code, to-do list and tickets, query language, agent interface, command line, data folder, Windows integration, updates, troubleshooting, building).

### Added

- Command-line options `--data-dir`, `--profile`, `--backup-dir`, `--lang`, `--no-tray`, `--reset-settings`, `--no-update-check`, `--version`, `--help` (`-h`, `-?`); `--option=value` form; a single folder argument (e.g. a folder dropped onto `paneldeck.exe`) opens like `--open`. Output goes to the calling console, otherwise to a message box; exit codes 0 (ok), 1 (error), 2 (invalid command line).
- Environment variable `PANELDECK_DATA` for a fixed data folder.
- `paneldeck.exe mcp` accepts `--data-dir`, `--profile` and `--lang`; started from a Paneldeck terminal, the bridge connects to the hub of that terminal.
- Data folder source, profile and active start options in *Settings → About* and in *Copy diagnostics*.
- Autostart and MCP registration per instance; *Settings → Window* shows whether autostart and the context menu belong to this instance, to another Paneldeck or are off.
- Ctrl+click on a title bar tab opens it in a new window; `list_sessions` reports the `window` of each session, and `focus_session` brings that window to the front.
- Empty Terminal Hub with *New terminal* / *New Claude session …* and shortcut hints.
- System prompt in the MCP `initialize` reply (`instructions`) and its editor under *Settings → Agents*; new data file `system-prompt.md` (backup `system-prompt.md.bak` on reset).
- Self-update from GitHub Releases with checksum verification; new release asset `SHA256SUMS.txt`.
- New optional fields: `settings.json` `mcp_prompt_lang`, `update_auto_check`, `update_last_check`, `update_skip_version`; `state.json` `extra_windows` and `window` per session.

### Changed

- **Unknown options and extra arguments on the command line are now an error** (exit code 2) instead of being ignored silently.
- Options that only affect the start of an instance (`--lang`, `--backup-dir`, `--no-tray`, `--no-update-check`, `--reset-settings`) are not handed over to an instance that is already running.
- Paneldeck starts without an open terminal when there are no sessions to restore.
- The `instructions` text of the MCP `initialize` reply is now the system prompt instead of a short fixed text. The error `hub_not_running` names the data folder that was searched.
- Registry entries (autostart, context menu) are written through the Windows API instead of `reg.exe`. A silent installer update keeps a deleted desktop shortcut and a switched-off context menu off.
- Uninstalling removes all MCP registrations of this Paneldeck (`paneldeck` and `paneldeck-*`), also without `claude` on the PATH, and the autostart entries of profile instances; the rest of `.claude.json` stays unchanged.
- The README is a short landing page; the detailed guides moved to `docs/en/` and `docs/de/`.

### Upgrade notes

- **Update from 2.0.0:** install over the old version or replace `paneldeck.exe` of the portable folder; settings, sessions, the database, prompts and themes are kept. The new fields are added on first save; 2.0.0 can still read the files (sessions of further windows then show up in the main window).
- **Self-update starts with 2.1.0:** 2.0.0 and older cannot update themselves, so install 2.1.0 by hand once. Releases from 2.1.0 on carry `SHA256SUMS.txt`; releases without it are only announced, never installed automatically.
- **Check your shortcuts and scripts:** an unknown option (for example a typo) now stops Paneldeck with an error instead of being ignored. `paneldeck.exe --help` lists every option. `--open`, `--claude`, `--tray` and `mcp` work as before.
- **Fresh start:** Paneldeck no longer opens a terminal by itself on a fresh start – press `Ctrl+Shift+T` or use the hint in the empty hub.
- **Profiles and agents:** the default instance keeps its entries (`Paneldeck` autostart, MCP server `paneldeck`) exactly as before. Register a profile instance from its own *Settings → Agents* to get `paneldeck-<profile>`.
- **Unsigned builds and antivirus:** the releases are still not code-signed. Microsoft Defender and other antivirus programs occasionally flag unsigned builds as malware (a false positive). Each release is scanned with Defender before publishing; compare the SHA-256 of your download with `SHA256SUMS.txt`, and see the troubleshooting guide if a scanner complains.
