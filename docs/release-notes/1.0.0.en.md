First public release. From here on, the public API (MCP interface, command line, data formats in the data folder) is binding in the sense of Semantic Versioning; earlier development states were not published.

> Independent open-source project – not affiliated with, endorsed by or reviewed by Anthropic.
> The installer and `paneldeck.exe` are **not code-signed** yet, so Windows SmartScreen may warn on first start ("More info" → "Run anyway"). See the README for details.

### Added

- **Terminals** with full emulation via ConPTY: PowerShell 7, Windows PowerShell, CMD, Git Bash and WSL distributions; colors, alt screen, mouse, Unicode, color emoji, CJK and seamless box-drawing characters.
- **Organization:** sessions in projects with their own layout, groups/folders (tree view), colors, tags, filters and notes; freely splittable panes, drag & drop (including folders), detach into their own windows, git worktrees per session.
- **Claude mode** (can be turned off): status display via hooks (working / approval? / ready), notifications, token and cost estimates with a cost overview, daily and per-session budget, history with exact resume, start dialog (model, permission mode), editor for `CLAUDE.md` and Claude settings.
- **Convenience:** command palette, history search, prompt library, broadcast to several terminals, file tree, git info, pasting files and images from the clipboard, tray, transparency, Windows notifications.
- **Agent interface (MCP)** with 15 tools (`whoami`, `list_sessions`, `read_terminal`, `screenshot`, `get_usage`, `search_history`, `create_session`, `send_text`, `send_keys`, `run_command`, `wait_for_status`, `queue_prompt`, `rename_session`, `focus_session`, `close_session`): off by default, levels "Read only" and "Control", access check in the hub, call log; agents identify themselves via `whoami` and create child sessions under their own.
- **Customization:** keyboard shortcuts, custom themes (JSON), terminal font, English (default) and German.
- **Windows integration without administrator rights:** installer (per user, with license page) and portable ZIP; Explorer context menu, optional autostart, single instance; uninstalling removes the hooks and the MCP registration again. Updating over a running hub is possible.
- MIT license (`LICENSE`); the license texts of the dependencies ship with the installer and the ZIP (`THIRD_PARTY_LICENSES.txt`).

### Security

- Paneldeck makes no connections to the internet and sends no telemetry; hook and MCP traffic stays local (`127.0.0.1`, with a token).
- All `unwrap()`/`expect()` calls in the program code were replaced by error handling (the release build aborts completely on a panic); the `unsafe` blocks are justified.
- The executable contains no paths of the build machine.
