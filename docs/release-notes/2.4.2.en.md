Paneldeck 2.4.2 is a bug-fix release for terminals that run on Windows' own console host (*Use the bundled console host* switched off) on older Windows versions: after a line that exactly fills the terminal width, the terminal no longer falls one line behind and the next command's echo is no longer drawn twice (#264). Settings, sessions, data and the agent interface stay compatible.

> Independent open-source project – not affiliated with, endorsed by or reviewed by Anthropic.
> The installer and `paneldeck.exe` are **not code-signed** yet, so Windows SmartScreen may warn on first start ("More info" → "Run anyway"). See the README for details.

### Fixed

- Only with Windows' own console host on older Windows versions (*Use the bundled console host* off): after a line that exactly fills the terminal width, the terminal no longer falls one line behind (missing blank line before the Git Bash prompt), and the next command's echo is no longer drawn twice (#264)
