First patch release after 1.0.0. The app, the installer and all messages are now English by default; German is available as an option everywhere.

### Changed

- The installer offers a language selection (English/Deutsch) at start; the component names, the Explorer context-menu entries and the uninstall shortcut follow the chosen language.
- All texts of the agent interface (error messages and notes; error codes and field names are unchanged), status messages, the diagnostics report, default prompts and git messages are English by default; German is used when the language is set to German in the settings.

### Fixed

- On systems whose language is neither German nor English, the installer no longer falls back to German but to English.
