Paneldeck 2.5.0 is the first release for **Linux** and – experimentally – **macOS**. On Linux (x86_64) it comes as AppImage (updates itself), `.deb`, `.rpm` and tarball, with tray icon, notifications, native file dialogs, optional start at login and "Open in Paneldeck" for Nautilus, Dolphin and Nemo; API keys are protected by the system keyring. The agent interface identifies its callers on Linux and macOS as strictly as on Windows. The **shell integration now covers zsh and fish** – command marks, exit codes, the current folder, exact `run_command` and the Claude status – in WSL and on Linux/macOS, without touching your startup files. The custom context length of local chats is now a slider in powers of two. Settings, sessions, data and the agent interface stay compatible.

> Independent open-source project – not affiliated with, endorsed by or reviewed by Anthropic.
> The installer and `paneldeck.exe` are **not code-signed** yet, so Windows SmartScreen may warn on first start ("More info" → "Run anyway"). See the README for details.

### macOS (experimental)
Paneldeck now runs on **macOS 12 or newer** – one universal app for Apple Silicon and Intel, as `Paneldeck-2.5.0-macos-universal.dmg` and `paneldeck-2.5.0-macos-universal.zip`. **The macOS version is experimental:** it is built and tested by GitHub Actions, but has seen little use on real Macs so far – please report problems as issues (mention "macOS" in the title; the checklist is section 67 of `TESTPLAN.md`). The app is **not signed or notarized**: open it the first time with right-click → *Open* (macOS 15: *System Settings → Privacy & Security → Open Anyway*) or `xattr -d com.apple.quarantine /Applications/Paneldeck.app`, and only for a download whose SHA-256 matches `SHA256SUMS.txt`. It has a menu-bar icon, notifications, start at login (LaunchAgent, off by default), keeps API keys encrypted with a key in the Keychain and updates itself (checked against `SHA256SUMS.txt` – this protects against transfer errors, not against a compromised release). Details: [macOS](https://github.com/zibbozz/paneldeck/blob/main/docs/en/macos.md).

### Added

- Shell integration for zsh and fish (#57): command marks (jump between commands, prompt end OSC 133;B), exit code and duration, the current folder (also OSC 7), exact `run_command` and the Claude status now also work in zsh and fish – in WSL and as shells on Linux/macOS – without touching your startup files (zsh through a temporary `ZDOTDIR` that restores your own, fish through `--init-command`; the helper files in the data folder are removed when Paneldeck exits). For WSL, Paneldeck detects the distribution's login shell in the background (retried after 45 s if it fails) and shows it in shell lists, e.g. "WSL: Ubuntu (zsh)"; until it is known bash gets its integration, fish gets it through `XDG_DATA_DIRS`, and zsh only once WSL can read the helper file. A multi-line system prompt keeps its line breaks in zsh and fish
- Profiles: "Shell in WSL" chooses the login shell per profile (automatic or an entry from the distribution's `/etc/shells`) (#57)
- Nested shells (ssh, tmux …) without shell integration are detected and shown as "without shell integration"; `run_command` then reports `quality: approx` (#57)
- *Settings → Terminal* offers copyable snippets for bash, zsh and fish to get command marks from remote machines (#57)
- Linux (x86_64) release: AppImage (updates itself, checked against `SHA256SUMS.txt`), `.deb`, `.rpm` and tarball, built by GitHub Actions with build provenance; minimum Ubuntu 22.04 / Debian 12 / Fedora 39, X11 and Wayland (#149)
- Linux: tray icon (StatusNotifierItem), desktop notifications, native file dialogs (XDG portal), optional start at login (XDG autostart) and optional "Open in Paneldeck" for Nautilus, Dolphin and Nemo; data folder `~/.local/share/Paneldeck` (private to the user); shells from `/etc/shells` started as login shells (#149)
- Linux: API keys of chat servers are encrypted with a key from the system keyring (Secret Service); without a keyring Paneldeck asks for a master password on the first access to a key (#149)
- Linux/macOS: the agent interface identifies the calling process itself (socket owner, complete process tree; on Linux Paneldeck is a subreaper) and refuses callers it cannot identify; programs that detach from a session stay restricted, as on Windows (#149)
- macOS version (experimental, not signed): one universal app for Apple Silicon and Intel (macOS 12 or newer) as `.dmg` and `.zip`. It has a menu-bar icon, notifications, start at login (LaunchAgent, off by default), native file dialogs and API keys encrypted with a key in the Keychain. The app updates itself, checked against `SHA256SUMS.txt` and its code signature. Clicking a path never starts an app, script or installer – it is only shown in Finder. The About page shows an "experimental" notice; how to open the unsigned app the first time is in [macOS](docs/en/macos.md) (#150)

### Changed

- Local chats: the custom context length in *Settings → Models* is now a slider in powers of two (4K, 8K … 512K, 1M; each step doubles the value, ←/→ move one step) with a number field next to it for any value from 256 to 16M; the short form (e.g. 32K) and the full number are shown. With the server default the slider is visible but disabled; older values that are not a step (e.g. 6000) are kept unchanged until the slider is moved (#305)

### Fixed

- File names dropped or inserted into a terminal are quoted for the shell that actually runs there (e.g. fish on Linux/macOS), so a crafted name can no longer run commands (#57)
- Folder names reported by the shell integration no longer contain control characters (#57)
- Paneldeck started in the tray (autostart, `--tray`) or minimized no longer takes the keyboard focus from the program you are working in
