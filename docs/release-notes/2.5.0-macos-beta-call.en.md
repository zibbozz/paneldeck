# Call for testers: Paneldeck on macOS (experimental)

Paneldeck 2.5.0 will be the first version for **macOS** (12 Monterey or newer, Apple Silicon and Intel). It is built and tested automatically on GitHub's macOS runners – but nobody on the team has a Mac. Before the release we are looking for a few people who try a test build on a real Mac for 20–30 minutes.

**What you need:** a Mac with macOS 12 or newer, ideally Claude Code installed (not required), and a GitHub account to report what you find.

**How:**
1. Download `Paneldeck-<version>-macos-universal.dmg` from the build linked below (artifact `paneldeck-<version>-macos` of the *Release build* / *CI* run) and check it: `shasum -a 256 -c --ignore-missing SHA256SUMS-macos.txt`.
2. Drag `Paneldeck.app` to *Applications*. The app is **not signed** (an Apple Developer ID costs money; Paneldeck is free): open it with right-click → *Open*, or on macOS 15 via *System Settings → Privacy & Security → Open Anyway*, or `xattr -d com.apple.quarantine /Applications/Paneldeck.app`.
3. Go through as much of the checklist as you like – each item is useful on its own:
   - Terminals: a zsh session starts as a login shell, Homebrew tools and `claude` are found, typing (also `@`, `|`, `{}` with Option) works.
   - Window: moving, resizing, maximizing, minimizing; looks sharp on a Retina display.
   - Menu bar icon: click shows the window, menu *Show Paneldeck* / *Quit*; *Close → tray* works.
   - A notification when a background session (e.g. Claude) is done.
   - *Settings → Window → Start at login*: Paneldeck starts minimized after logging out and in again.
   - Fonts: your installed monospace fonts (e.g. a Nerd Font) are in the list and work.
   - A chat server with an API key: the Keychain question, and that it still works after a restart.
   - The agent interface (MCP) with Claude Code, if you use it.
4. Report each problem as an issue and mention "macOS" in the title (macOS version, Apple Silicon or Intel, what you did, what happened; a screenshot helps). "Everything worked" is a welcome comment too.

Thank you! The checklist with all details is section 67 of `TESTPLAN.md`.

## Paragraph for the 2.5.0 release text

### macOS (experimental)
Paneldeck now runs on **macOS 12 or newer** – one universal app for Apple Silicon and Intel, as `Paneldeck-2.5.0-macos-universal.dmg` and `paneldeck-2.5.0-macos-universal.zip`. **The macOS version is experimental:** it is built and tested by GitHub Actions, but has seen little use on real Macs so far – please report problems as issues. The app is **not signed or notarized**: open it the first time with right-click → *Open* (macOS 15: *System Settings → Privacy & Security → Open Anyway*) or `xattr -d com.apple.quarantine /Applications/Paneldeck.app`, and only for a download whose SHA-256 matches `SHA256SUMS.txt`. It has a menu-bar icon, notifications, start at login (LaunchAgent, off by default), keeps API keys encrypted with a key in the Keychain and updates itself (checked against `SHA256SUMS.txt` – this protects against transfer errors, not against a compromised release). Details: [macOS](https://github.com/zibbozz/paneldeck/blob/develop/docs/en/macos.md).
