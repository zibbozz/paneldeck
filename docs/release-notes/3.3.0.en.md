Paneldeck 3.3.0 brings a **smart mode** to the editor: a language server you have installed adds **completion** and **diagnostics** (squiggles, a problem list, F8) to the syntax colours, but only in folders you trust. The editor also gets **multiple cursors like Sublime Text** (each part switchable, off by default), **toggle comment** and **typing directly in the comparison tab**. The **settings** are now their own window with a searchable category tree, markers for modified settings and per-row reset. Nothing is downloaded: smart mode uses language servers that are already on your PATH or that you point it to. Settings, chats, sessions and the agent interface stay compatible.

### Added

- Editor: **type directly in the comparison tab** – click into an editable side (a document, not the saved file, a git state or the clipboard) and type, delete, paste, cut and copy a selection, press Enter or Tab, move with the arrow keys, Home/End and Page Up/Down (Shift selects), Ctrl+A selects the side. The text appears at once; the differences are recomputed about 300 ms after the last key. The cursor skips filler lines (a click on one puts it at the end of the line above), typing in a collapsed region expands it. Typing shares the undo history of the document with the block arrows and the normal tab (Ctrl+Z/Y on the focused side); Alt+←/→, Ctrl+S and double-click to open the line in the normal tab work as before. Without a cursor the arrow keys scroll as before; typing into a read-only side shows a hint. One cursor only – multiple cursors in the comparison come later (#391).
- Editor: **multiple cursors like Sublime Text**, each part with its own switch in *Settings → Editor → General* (all off by default): *Multiple cursors* turns on the shortcuts and commands – **Ctrl+D** adds the next occurrence, **Ctrl+Shift+D** selects all occurrences (in the Editor tab; in the Terminal Hub it still splits right), **Ctrl+U** takes back the last cursor or selection change without touching the text. *Middle mouse button*: dragging selects a column (with word wrap by screen rows; short and empty lines get a cursor at their end) and replaces the cursors, **Ctrl+drag** adds the column, a click places the cursor, **Ctrl+click** adds one. *Alt+click* adds a cursor, Alt+click on a cursor removes it (the last one stays). At most 10 000 cursors ("Only the first 10 000 cursors."). The status bar shows "3 cursors" or "3 selections" instead of line and column (#394).
- Editor: new menu **Selection** in the menu bar (add next occurrence, select all occurrences, undo cursor/selection change, single cursor, select line); all of it also in the command palette. The multi-cursor shortcuts are in *Settings → Shortcuts* and can be changed or removed (#394).
- Editor: **Toggle comment** (**Ctrl+/**, *Edit* menu, command palette) on the lines of every cursor, with the line comment of the file's language (`//`, `#`, `--`, `;`, `%`, `'`, `REM`); greyed out for languages without line comments. A second binding can be set in *Settings → Shortcuts* (on German keyboards `/` is Shift+7) (#394).
- Agent interface: `editor_read` additionally returns the user's cursors and selections (`selections`, 1-based line/column, at most 1000) – only with the new switch *Agents see the selections* (*Settings → Agents → Editor*, off by default); `editor_list` reports the switch in `agents.selections` (#394).
- Editor: **Smart mode** (mode picker in the status bar, per file, per language or as default): a language server adds **completion** and **diagnostics** to the syntax colours. Servers come from PATH (a fresh Windows PATH, resolved to an absolute file, never from the project folder; npm `.cmd` shims run through `cmd`, the rustup proxy and the Microsoft Store Python stub are recognised) or from an own path per language – built-in list: rust-analyzer, basedpyright/pyright/pylsp, typescript-language-server/tsgo, clangd, gopls, lua-language-server, csharp-ls, vscode json/html/css, yaml-language-server, taplo, bash-language-server, texlab, phpactor, ruby-lsp, neocmakelsp, marksman, docker-langserver, jdtls, kotlin-language-server, perlnavigator, lemminx, sourcekit-lsp, each switchable per language; PowerShell, NSIS and SQL with an own path only. The project root is detected (Cargo.toml, package.json, pyproject.toml, go.mod, … or `.git`). Limits (configurable): at most 6 servers (the one unused longest ends), completion timeout 5 s, 1000 diagnostics per file, messages up to 64 MB, smart mode up to 5 MB per file (above: Syntax mode with a hint), a server without open documents ends after 10 minutes, diagnostics (pushed by the server or pulled, LSP 3.17) after a 500 ms typing pause; after 3 crashes within 5 minutes smart mode is off for that language until restart, with a bar offering *Retry* and *Show log*. Own servers take arguments, and `initializationOptions` per language can be set in `settings.json`. **WSL files:** the server runs inside the distribution (`wsl.exe -d <distro> --cd <root> --exec <server>`), found in the distribution's Linux PATH, with paths mapped both ways; root and server are looked up in the background. Each server runs without a window in its own job object and never starts programs from the project folder; requests of a server to change files, run commands or open documents are refused; `..` in paths is resolved before the trust check; arguments with cmd special characters are refused for `.cmd`/`.bat` wrappers (#367).
- Editor: **folder trust** for smart mode – a bar above the text offers *Trust* (the detected project root), *Trust parent folder …* and *Not now*; until then Syntax mode runs. UNC and WSL folders count only as exactly that folder. Trusted folders are listed in *Settings → Editor → Smart mode* and can be revoked there (the servers stop at once); agents can never change them (#367).
- Editor: **completion** opens after the server's trigger characters and after 2 typed word characters (~100 ms pause, switchable) and with **Ctrl+Space**; up to 12 rows with kind, name and detail, documentation beside the selection, local fuzzy filtering; Tab or Enter accept, Esc closes, arrow keys select; snippets with tab stops (Tab jumps, Esc ends) as one undo step (#367).
- Editor: **diagnostics** as squiggles in theme colours (hints dotted, deprecated struck through), the message on hover and for the cursor line in the status bar; error/warning counter in the status bar, **problem list** at the bottom of the Editor tab (counter or **Ctrl+Shift+M**), **F8/Shift+F8** for the next/previous problem. Diagnostics are shown about 500 ms after the last change; stale ones are dropped. Not in the comparison tab (#367).
- Editor: window **Language servers** (status bar, click on the server): language, folder, status, PID, memory, *Restart*, *Stop* and the server's log (in memory only, at most 1 MB; message trace switchable, off by default) (#367).
- Themes: new colours `diag_error`, `diag_warning`, `diag_info`, `diag_hint` for the squiggles (#367).

### Changed

- **Settings window reorganized** like JetBrains IDEs: it is now an **own window** (movable outside the hub; size and position are kept while Paneldeck runs, always opaque in the theme colours) with a **searchable category tree** on the left – General, Appearance, Terminal, Editor, Shortcuts, Claude, Models, Agents, Data & backup, About – and one page per topic on the right with a breadcrumb ("Agents › Access", the area is clickable). It always opens on the start page; below about 700 px width the tree becomes a picker at the top. Nothing was removed, but several settings moved: terminal behaviour (scrollback, blinking cursor, mouse wheel, Shift+Enter, console host) is under *Terminal › Behaviour*, OSC 52 and multi-line paste under *Terminal › Clipboard & paste*, profiles under *Terminal › Profiles*, the former *Window* tab under *General › Window & tray* and *General › Windows integration* (including the editor's Explorer entry), the editor's agent switches under *Agents › Editor*, the Claude defaults (before: tabs Claude | Access | Advanced) are three pages *Claude › New sessions / Access / Advanced*; where a setting moved, a link remains at the old place (#395).
- Settings: **search** finds pages, sections, settings, their hints and shortcut names – German and English always both match ("opacity" finds "Deckkraft"), plus curated keywords (also the old tab names). The tree shows only pages with hits and their count ("4 hits on 3 pages"), the page only the matching rows with the hit highlighted; hidden rows are named with *Show all*. The search field has the focus when the window opens, **Ctrl+F** jumps there, **Esc** first clears it, then closes the window (#395).
- Settings: settings that differ from their default get a **marker bar** on the row and a count in the tree; the filter *Only modified* shows only those. **↺ resets** a single row, *Reset page* the whole page; risky ones (remember sessions, MCP level, agent access, Windows integration, global hooks and other security settings, and lists you entered such as own language mappings, modes per language, exclude patterns and prices) ask first. Changes still apply instantly (#395).
- Settings: keyboard – **↑/↓** change the page, **←/→** collapse/expand an area, **Tab** goes into the form, **Ctrl+Tab**/**Ctrl+Shift+Tab** next/previous page. The command palette lists every page as "Settings: …" (#395).
- Editor: the existing multi-cursor features are **off by default** after the update – Alt+click, Ctrl+D and selecting all occurrences only work after switching on *Multiple cursors* or *Alt+click* in *Settings → Editor → General* (#394).
- Editor: pasting with several cursors always pastes the whole clipboard at every cursor (before, a clipboard with as many lines as cursors was distributed line by line) (#394).
- Editor: Ctrl+D (next occurrence) matches the selected text everywhere, no longer only whole words (#394).

### Removed

- Editor: Alt+Shift+Up/Down (cursor above/below) and column selection with Alt+Shift+drag or Alt+drag – column selection is now done with the middle mouse button; Ctrl+Shift+L (all occurrences) is now Ctrl+Shift+D. Ctrl+Alt+arrow keys still move the focus between splits (#394).
