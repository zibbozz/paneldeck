Paneldeck 2.3 is about the terminal itself and about keeping control of what runs in it: **modern keyboard protocols, links, notifications and fonts**, a **bundled, newer console host**, **background programs that stay with their session** (Windows Job Objects), **reload and settings per session** with more **Claude start options**, **WSL sessions in Linux folders**, and for the to-do list and tickets **built-in descriptions, due dates and labels**, an **icon explorer** and an **editable color palette**. It is a minor version: settings, sessions and the agent interface (MCP) stay compatible; the database gets a new schema version and project backups a new format – see *Upgrade notes*.

> Independent open-source project – not affiliated with, endorsed by or reviewed by Anthropic.
> The installer and `paneldeck.exe` are **not code-signed** yet, so Windows SmartScreen may warn on first start ("More info" → "Run anyway"). See the README for details.

### Highlights

- **A better terminal (#183):** the kitty keyboard protocol and win32-input-mode (Shift+Enter, Ctrl+Backspace, Esc, Alt and Ctrl combinations arrive unambiguously), links set by programs (OSC 8, Ctrl+click, with strict safety rules), notifications, bell markers and progress from programs (sidebar and taskbar), any installed monospace font such as Nerd Fonts with gap-free Powerline symbols, bold/italic and underline styles, copying to the clipboard from programs (OSC 52, e.g. Claude Code in WSL or SSH) and a warning before pasting several lines.
- **Bundled console host:** the installer and the ZIP now include a newer ConPTY from Microsoft (`conpty.dll`, `OpenConsole.exe`, 1.25). Full-screen programs flicker less; *Settings → Appearance → Use the bundled console host (recommended)* switches back to the console host of Windows.
- **Background programs stay with their session (#168):** every terminal's shell runs in its own Windows Job Object. Programs started from a session – also detached, also `code .`, a browser or `wt` – belong to it. Closing or reloading a session, closing a window or quitting lists the programs that would keep running and offers *Keep running* or *End all* ("End all" terminates them immediately, without saving).
- **Reload and session settings (#169, #170):** a reload button in the pane header restarts the shell or Claude Code; *Settings …* in the sidebar context menu changes profile, shell, start folder, name, color, tags, notes and the Claude options of an existing session.
- **Claude start options (#161, #182):** model, effort, permission mode and agent, plus switches (`--chrome`, `--ide`, `--verbose` …), extra folders, allowed/disallowed tools, an MCP config, a system prompt addition, a fallback model, a budget and auto-compact – as defaults, per session and when reloading; *Continue the conversation* per session.
- **Sessions:** WSL sessions start in a Linux folder of your choice (#172); minimized sessions open alone, Ctrl+Tab reaches them too (#162); close all sessions of a folder, project or everything at once, middle-click closes (#155, #156); *Remember sessions* can be switched off (#157).
- **To-do list and tickets (#188, #195, #190, #173):** every ticket has a built-in description, due date and labels; due dates get configurable markers (by default a yellow triangle under 1 week and a red one under 1 day) in lists, boards, cards and the simple to-do list; the query language knows `due`, `description` and `labels`; an icon explorer with more than 2,000 Lucide icons; and an editable color palette for all color pickers.
- **Agents (MCP):** `placement` for `focus_session`/`create_session`, Claude start options for `create_session`, `remaining_processes` from `close_session`, `progress`, `shown` and `console_host` in `list_sessions`, due dates and labels for tickets and to-do cards, richer `send_keys`; agent chains keep agents from writing back into the sessions they descend from.

### Added

- Terminal: kitty keyboard protocol; win32-input-mode under ConPTY; setting *Shift+Enter = new line in PowerShell* (off by default); `TERM_PROGRAM=Paneldeck` and `TERM_PROGRAM_VERSION`; replies to color, size and XTVERSION queries (also in the background); focus events (DECSET 1004).
- Links set by programs (OSC 8) open with Ctrl+click; the tooltip shows the real target and host.
- Notifications from programs (OSC 9, OSC 777) for sessions you are not looking at; a bell marks the session in the sidebar (optional toast); progress (OSC 9;4) in the sidebar and on the taskbar button – each with its own setting under *Settings → Notifications*.
- Any installed monospace font as the terminal font, with Powerline, box-drawing and block characters drawn by Paneldeck; bold, italic, underline styles and colors; a blinking cursor on request (setting).
- Setting *Allow programs to copy to the clipboard (OSC 52)* (on by default) and *Warn before pasting multiple lines* (on by default).
- Bundled console host (ConPTY 1.25) with the setting *Use the bundled console host (recommended)*; MCP `list_sessions` reports `console_host`.
- Background programs in Job Objects: the close, reload, close-window and quit confirmations list them (name, PID, window title) with *Keep running* / *End all*; MCP `close_session` reports them in `remaining_processes`.
- Reload button (pane header, detached windows, palette, sidebar context menu, optional shortcut *Reload session*); session settings dialog with *Reload now?*; *Continue the conversation* per session.
- Claude start options as defaults (*Settings → Claude*), per session and under *More Claude options*; MCP `create_session` takes `model`, `effort`, `permission_mode`, `agent` and `claude_flags`; `list_sessions`, `whoami` and `create_session` report them plus `claude_user_options` (names only).
- WSL start folders: *Windows path / WSL path* switch, all installed distributions, Linux path completion with a check, the folder dialog in the distribution's home, recently used WSL folders; Linux default folders for tree folders and projects; *Open in Paneldeck* on `\\wsl.localhost\…` opens a WSL session; MCP `create_session` accepts Linux paths as `cwd` and reports `cwd_checked`.
- Placement for agents: `placement` (`replace`, `split_right`, `split_down`, `solo`) for `focus_session` and `create_session`; `list_sessions` reports `shown`. Ctrl+Tab also reaches minimized sessions.
- Close all sessions (folder trash button, button next to the filter field, project context menu, palette, optional shortcut); middle-click closes a session; setting *Remember sessions*; setting *Inherit Paneldeck's environment*; context menu *Reset agent chain*.
- Built-in fields Description, Due date and Labels on every ticket type; due markers with thresholds per project (tab *Due dates*) and for the to-do list (*Due dates …*); due dates, sorting and a filter for to-do cards; counts such as "3 overdue"; new icon "alert".
- Query language: `due`, `description`, `labels`, custom fields by key, built-in fields by their English and German names.
- MCP: `description`, `due`, `labels` for `create_ticket`/`update_ticket`, `due` for `add_todo`, `due`/`due_state`/`labels` in answers, `due_thresholds` in `list_projects`; `send_keys` with `ctrl+`/`alt+`/`shift+` combinations and many more keys, encoded like the keyboard; `list_sessions` reports `progress`.
- Icon explorer with the Lucide icon set (*More icons …* in every icon picker); icons stored as `lucide:<name>`.
- Editable color palette (*Settings → Colors*): shared or per area, add, edit, name, reorder and delete colors (with *Undo*), restore defaults, *Copy from shared palette*, and *Custom color …* in every color picker.

### Changed

- Restoring a minimized session from the sidebar or the palette opens it alone (the other panes are minimized); Ctrl+Shift+W only minimizes. MCP `focus_session` uses `placement` (default `replace`).
- A WSL session without a start folder starts in the Linux home (`~`).
- Ctrl+Backspace sends `0x08` like Windows Terminal; Esc is sent as a win32-input-mode key event under ConPTY; `reset` restores colors changed by programs.
- Updates replace `paneldeck.exe`, `conpty.dll` and `OpenConsole.exe` together, also while Paneldeck is running; uninstalling removes the console host too.
- MCP `create_session` refuses value options it used to ignore (e.g. `add_dir`, `mcp_config`, `safe_mode`) with `bad_args`, Linux paths for Windows shells and `\\wsl$` paths of another distribution.
- Agent chain: only sessions created by an agent that itself has a chain are marked; sessions created by an agent you started may write back into it.
- Existing description and "Labels" fields become the built-in fields on update (values, history and rules are kept); project backups use format version 3; due dates are stored as `YYYY-MM-DD` or `YYYY-MM-DDTHH:MM`.
- Everything that works like a button shows the hand cursor; the cost summary and the MCP chip look like small buttons.

### Deprecated

- `state.json`: the `slot` field of minimized sessions (2.2.0) is no longer used or created and will be removed in 3.0.0.

### Fixed

- MCP `run_command` and jumping between prompts work when a line exactly fills the terminal width and when the scrollback is full (#193, #197); `read_chat` keeps the end of long tool results (#194).
- Alt+digit and Alt+punctuation sent nothing; Alt shortcuts used by Paneldeck no longer leak characters; broadcast encodes keys per terminal; kitty flags left by a crashed program are cleared at the next prompt.
- OSC 52 copying (e.g. from Claude Code in WSL or SSH) arrives on the Windows clipboard.
- Terminals no longer inherit internal `PANELDECK_*` variables; no see-through gap next to the sidebar (#160); a middle-click with a slight movement no longer starts a drag; the query bar knows fields added after the first query.

### Security

- Agent chains (#152): sessions created by agents inherit the creator's chain; no agent may write into, rename, focus or close a session of its own chain. The hub identifies the calling process itself and attributes it by Job Object membership (detached and orphaned processes included), with the process tree as a fallback. This protects against agents that are steered into misusing other sessions, not against malicious programs running as your own user.
- Agents can never set `bypassPermissions`; sessions created via MCP without a permission mode get `--permission-mode default`. Agents can only add harmless Claude switches; your defaults for extra folders, allowed tools, an MCP config and `--safe-mode` never apply to their sessions.
- OSC 8 links: only plain http/https links open directly; overlong or disguised targets, script schemes, misused Windows protocol handlers and `file:` links to non-local paths are never opened; network and device paths never count as local.
- Pasted text, window titles and notification texts are cleaned; OSC 52 is write-only and limited; a program pushing thousands of keyboard modes can no longer crash Paneldeck.
- Paneldeck no longer loads DLLs from the current folder, loads the bundled console host by its full path and links the C runtime statically.
- WSL start folders containing `"` or `\` are rejected; network paths are refused as `cwd` without being accessed.

### Upgrade notes

- **Update from 2.2:** install over the old version or replace the files of the portable folder – from 2.3 on `paneldeck.exe` together with `conpty.dll` and `OpenConsole.exe` from the ZIP. Settings, sessions, prompts and themes are kept.
- **Database:** `paneldeck.db` is updated to schema version 9 (built-in description, due date and labels, due thresholds); Paneldeck backs it up first. Existing description fields and custom fields named "Labels" become the built-in fields with their values and history; a required description becomes optional, and these fields lose their default value. Other custom fields with the name of a built-in field are renamed "… (custom)" – agents that set them by their old name now reach the built-in field.
- **Going back to 2.2:** 2.2 refuses the updated database. Quit Paneldeck, copy the database backup made before the update over `paneldeck.db`, then start 2.2; changes made since then are lost. 2.2 reads `settings.json` and `state.json` but drops the new fields when it saves.
- **Project backups and templates:** exports use format version 3 and can't be imported into versions before 2.3, nor can files with Lucide icons. Version 1 and 2 backups still import.
- **New optional fields:** `settings.json` gets `remember_sessions`, `inherit_env`, `bundled_conpty`, `osc52_copy`, `warn_multiline_paste`, `shift_enter_newline_powershell`, `cursor_blink`, `program_notify`, `progress_indicator`, `bell_toast`, `wsl_recent`, `palette`, `claude_defaults` and `last_claude_opts`; `state.json` gets `claude_opts`, `claude_continue` and `agent_chain` per session. Details: *Data folder and backups* in the documentation.
- **Background programs:** programs started from a terminal now belong to that session's Job Object. When you close a session, they keep running unless you choose *End all*; they can no longer break away from the job.
- **If a session doesn't start** or full-screen programs behave oddly, switch off *Settings → Appearance → Use the bundled console host (recommended)* and report the problem.
- **Unsigned builds and antivirus:** Microsoft Defender and other antivirus programs occasionally flag unsigned builds as malware (a false positive). Each release is scanned with Defender before publishing; compare the SHA-256 of your download with `SHA256SUMS.txt`, and see the troubleshooting guide if a scanner complains.
