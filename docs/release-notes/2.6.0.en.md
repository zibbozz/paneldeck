Paneldeck 2.6.0 is about **keeping things tidy**. A new **Clean up** window shows what Paneldeck stores and how much space it takes, and deletes exactly what you tick. The data folder is saved as a ZIP first if you reset everything. The new **process list** runs dev servers and watchers apart from your terminal sessions, with start/stop/restart, output and autostart. Expert projects get a **Maintenance** page that finds stale, overdue and inconsistent tickets and unused configuration, takes a database backup and then fixes them. It never deletes tickets. It also has a ticket **archive** and database care (check, compact, repair, rescue). The new **theme editor** lets you build and check your own themes with a live preview, using named interface colours. Agents can read all of this through new read-only tools and start/stop the user's processes. Settings, sessions and themes stay compatible. Project backups now use format version 4 and the database moves to schema 10, with a backup first.
